# 表情系统说明

## 功能概述

Baal 桌面宠物现在支持动态表情系统，可以在对话时显示不同的表情，让互动更加生动。

## 主要特性

1. **动态基础动画**：使用 `巴力2.gif` 作为基础动画，替代原来的静态图片
2. **表情叠加**：支持 7 种不同的表情，叠加在基础动画上方
3. **自动表情切换**：根据对话内容自动切换合适的表情
4. **流式处理**：表情标记不会显示在对话气泡中
5. **默认表情**：启动时显示正常表情 (`正常.png`)
6. **前置表情**：表情在句子开头出现，说话时就显示对应表情

## 表情对应关系

- `<#1>` - 开心/愉悦（嘲笑仆人时）
- `<#2>` - 得意/满足（仆人服从时）
- `<#3>` - 无语/不屑（仆人犯蠢时）
- `<#4>` - 鄙视/轻蔑（看不起仆人时）
- `<#5>` - 平静/正常（一般状态）
- `<#6>` - 生气/愤怒（仆人偷懒时）
- `<#7>` - 暴怒/极度愤怒（严重违抗时）

## 技术实现

### 1. 表情管理器 (EmotionManager)
- 预加载所有表情资源
- 管理表情标记到图片文件的映射
- 提供表情提取和获取功能

### 2. LLM 提示词更新
- 在系统提示词中加入表情使用规则
- 指导 AI 在句子开头添加表情标记
- 格式：`<#n>你要说的话。`
- 确保表情标记格式统一

### 3. 流式输出处理
- 在 AsyncWorker 中检测表情标记
- 使用缓冲区机制处理前置表情标记
- 检测到表情后立即更新显示
- 从文本流中移除表情标记
- 发送清理后的文本到聊天气泡

### 4. 绘制系统
- paintEvent 中先绘制基础动画帧
- 在动画上方叠加当前表情图片
- 支持动态缩放以适应不同宠物大小

```
└── 生气2.png
```

## 注意事项

1. 所有表情图片已经与 gif 动画对齐，可以直接叠加
2. 表情标记 `<#n>` 不会显示在聊天气泡中
3. 如果 gif 加载失败，会回退到原来的静态图片
4. 表情切换会触发窗口重绘，确保及时更新显示
