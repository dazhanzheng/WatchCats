# 监督模式使用指南

## 功能概述

监督模式是 Baal 桌面宠物助手的核心功能之一，旨在帮助用户保持专注，提高工作效率。

### 主要特性

1. **双层目标体系**
   - **长期目标**：一段描述性文字，定义您的最终目标
   - **短期目标**：具体的任务列表（最多5项），今天要完成的事项

2. **智能监控**
   - 每5分钟自动检查您的电脑使用情况
   - 自动检测AFK（离开）状态，避免无效提醒
   - 获取多时段数据（5分钟、2小时、全天）进行综合分析

3. **个性化提醒**
   - 基于当前人设（严格主人/嘲讽管家/温柔伴侣）生成提醒内容
   - 根据偏离程度（轻微/中度/严重）调整提醒强度
   - 自动显示主界面和对话气泡

4. **便捷操作**
   - 主界面上的快速开关按钮（绿色眼睛图标）
   - 一键启停，无需重复设置
   - 目标自动保存，下次启动直接使用

## 使用方法

### 1. 首次设置

1. 点击主界面上的 👁 按钮（或右键菜单选择"监督模式"）
2. 在弹出的设置对话框中：
   - 输入**长期目标**（例如："完成毕业论文，保持高效学习"）
   - 添加**短期目标**（例如："写第三章"、"整理参考文献"）
3. 点击"🚀 开始监督"按钮

### 2. 快速开关

- **开启**：点击白色的 👁 按钮，按钮变为绿色表示已激活
- **关闭**：点击绿色的 👁 按钮，按钮变回白色表示已停止

### 3. 修改目标

1. 右键点击主界面，选择"监督模式"
2. 在设置对话框中修改目标
3. 点击"开始监督"更新设置

## 工作原理

### 检查流程

```
每5分钟 → 检查AFK状态 → 如果活跃 → 获取活动数据 → AI评估 → 决定是否提醒
```

### AFK检测

- 如果过去5分钟内有超过4分钟处于AFK状态，则跳过检查
- 避免在您离开电脑时发出无效提醒

### 智能评估

系统会将以下信息发送给AI进行评估：

1. 您的长期和短期目标
2. 过去5分钟的应用使用情况
3. 过去2小时的活动模式
4. 今日（凌晨4点起）的整体使用统计
5. 当前的人设模式

AI会判断：
- 是否需要提醒（should_remind）
- 偏离程度（deviation_level）
- 个性化提醒内容（reminder_message）

### 提醒机制

当检测到偏离时：
1. 主窗口自动显示并置顶
2. 对话气泡弹出显示提醒消息
3. 根据偏离程度设置显示时长：
   - 轻微/中度：10秒
   - 严重：15秒

## 配置要求

### 必需组件

1. **ActivityWatch**：必须运行在端口5600
2. **API密钥**：需要配置OpenAI兼容的API（如DeepSeek）
3. **网络连接**：用于AI评估

### 推荐设置

- 设置3-5个明确的短期目标
- 长期目标控制在100字以内
- 选择适合的人设模式：
  - 严格主人：适合需要强力督促的场景
  - 嘲讽管家：适合喜欢挑战的用户
  - 温柔伴侣：适合需要鼓励的用户

## 常见问题

### Q: 监督模式无法启动？
A: 请检查：
1. 是否配置了API密钥（设置 → API配置）
2. ActivityWatch是否正在运行
3. 网络连接是否正常

### Q: 没有收到提醒？
A: 可能原因：
1. 您的活动符合设定的目标
2. 您处于AFK状态
3. AI判断偏离程度较轻

### Q: 提醒太频繁？
A: 可以：
1. 调整短期目标，使其更具体
2. 切换到较温和的人设
3. 暂时关闭监督模式休息

### Q: 目标没有保存？
A: 目标会自动保存到 `~/.baal_pet/supervision.json`，如果遇到问题请检查文件权限。

## 技术细节

### 数据存储

- 配置文件：`~/.baal_pet/config.json`
- 监督设置：`~/.baal_pet/supervision.json`

### 日志位置

- 主日志：`~/.baal_pet/logs/baal.log`
- 包含监督模式的所有活动记录

### API调用

- 每次评估消耗约500-1000 tokens
- 建议使用支持流式响应的API提供商
